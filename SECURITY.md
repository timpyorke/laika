# Security Policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use the
repository's **Security > Report a vulnerability** flow to create a private
report. If private vulnerability reporting is unavailable, contact the
repository owner privately before sharing technical details.

Include the affected version or commit, reproduction steps, expected impact,
and any suggested mitigation. Do not include real credentials or personal data.

## Supported versions

Laika is currently pre-release. Security fixes are applied to the latest main
branch and the newest published release once public releases begin. Older
development snapshots are not supported.

The current security model, data handling, and known residual risks are
documented in [docs/security-and-privacy.md](docs/security-and-privacy.md).
